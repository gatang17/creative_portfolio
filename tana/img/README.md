# Fotos del sitio

Las fotos se declaran con una variable CSS, no con `<img>`:

```html
<div class="photo photo--wide" style="--photo:url('img/mi-foto.jpg')"></div>
```

Mientras el archivo no exista, el bloque muestra un degradado verde de la marca:
la maqueta se ve completa y no aparecen iconos de imagen rota. Basta con dejar
el JPG con el nombre de abajo para que entre en su sitio.

Tamaños recomendados: heros y franjas a sangre 2000px de ancho,
fotos de sección 1200px, retratos 900px, logos de prensa 400x400.
